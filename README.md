###### **Personal Expense \& Budget Tracker**

###### **1. Project Overview**



The Personal Expense \& Budget Tracker is a Python-based application that helps users record, manage, and monitor their daily expenses. It allows users to organize expenses into different categories, set monthly budgets, and generate spending summaries.



The application uses CSV and JSON files to store data permanently.



###### **2. Objectives**

Develop a simple expense management application using Python.

Record daily expenses with date, category, description, and amount.

Organize expenses into different categories.

Set and monitor monthly budgets.

Calculate daily and monthly spending totals.

Generate category-wise spending summaries.

Implement search and filtering functionality.

Practice Python functions, collections, file handling, and exception handling.

###### **4. Project Features**

Add Expense: Record a new expense with date, category, description, and amount.

View Expenses: Display all recorded expenses.

Edit Expense: Modify existing expense details.

Delete Expense: Remove unwanted expense records.

Set Monthly Budget: Define a spending limit for a particular month.

Daily Summary: Calculate total expenses for a selected date.

Monthly Summary: Calculate monthly expenses and remaining budget.

Category-wise Summary: Display spending for each expense category.

Search and Filter: Find expenses using description, category, and month.

Data Storage: Save records using CSV and JSON files.
